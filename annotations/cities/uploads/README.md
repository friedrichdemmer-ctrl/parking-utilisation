# Uploaded source documents

Where a source could not be read automatically (an unreadable PDF, a login-walled article), save the
document here and name it `<city-file-slug>_<item-number>.pdf` (for example `germany_freiburg_10.pdf`;
the slug and item number are the ones in the matching `<slug>.draft.json` / `.verdict.json`).
Tell Claude it is there: the item is then re-checked against the uploaded text and, if it holds,
its "unconfirmed" label is removed.
